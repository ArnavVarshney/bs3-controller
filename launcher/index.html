Device

Static page, no install — USB via WebHID (Win/Mac/Linux, Chrome/Edge), BLE via WebBluetooth GATT (Win/Mac), backend at 127.0.0.1:8765 when running. Dangerous commands (0xDF brick, 0x06 reset…) are blocked client-side. Diagnostics page.
